블로그 도우미 개인정보처리방침

시행일: 2026년 10월 25일

1. 이 앱은 무엇인가요

블로그 도우미는 운영자 본인이 자신의 블로그(블로그스팟·워드프레스 등)에 올릴 글을 준비하고 발행하기 위해 쓰는 개인용 도구입니다. 다른 사람에게 서비스하지 않습니다.

2. 구글 계정 데이터를 어떻게 쓰나요

  • Blogger API 권한(https://www.googleapis.com/auth/blogger)으로 운영자 본인의 블로그에 글을 작성·임시저장·발행하는 데에만 씁니다.
  • 구글 계정의 다른 데이터(메일, 연락처, 드라이브 등)는 요청하지도, 읽지도 않습니다.
  • 구글 사용자 데이터를 판매하거나 제3자에게 넘기지 않으며, 광고 목적으로 쓰지 않습니다.

3. 무엇을 어디에 저장하나요

  • 구글 연결용 토큰은 운영자의 비공개 GitHub 저장소 비밀값(GitHub Secrets)에만 암호화되어 저장됩니다.
  • 작성한 글과 발행 기록은 운영자의 비공개 GitHub 저장소에 저장됩니다.
  • 이 웹페이지의 설정 값은 사용 중인 기기의 브라우저 저장소에만 저장됩니다.

4. 연결을 끊고 싶다면

구글 계정 → 보안 → "타사 앱 및 서비스"에서 blog-helper의 액세스를 언제든 삭제할 수 있습니다. 삭제하면 이 도구는 더 이상 블로그에 접근할 수 없습니다.
