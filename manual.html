0. 블로그 도우미가 다른 이유

설치 프로그램이 아니라, 매주 바뀌는 검색 규칙을 따라가는 서비스예요

PC에 설치하는 프로그램은 산 그날의 규칙으로 멈춰 있어요. 하지만 블로그 검색 규칙은 계속 바뀌어요. 블로그 도우미는 인터넷 창에서 돌아가서, 규칙이 바뀌면 여러분이 아무것도 하지 않아도 다음 글부터 바로 바뀐 규칙으로 써요.

최근 바뀐 것블로그 도우미가 하는 일
네이버 — AI(대형 언어 모델)로 글의 맥락·신뢰도를 평가하고, 자동 생성 저품질 글·경험 없는 글·살짝 바꾼 복사 글을 걸러내는 방향으로 바뀌고 있어요. AI 브리핑(검색 결과 위 AI 요약)도 생겼어요.1차 출처 확인, 직접 경험을 채울 자리 표시, 예전 글과 겹침 검사, AI 브리핑에 인용되기 쉬운 구성
구글 — 2026년 8월 스팸 업데이트에서 AI로 대량 생산한 글과 얇은 제휴(어필리에이트) 페이지가 크게 떨어졌어요.하루 공개 발행 수 제한, 품질 검사에 떨어진 글은 공개 금지, 상위 글이 빠뜨린 정보 위주로 작성
공정위 — 2024년 12월부터 대가를 받은 글은 제목이나 본문 첫 부분에 표시해야 해요.광고 문구를 항상 글 맨 위에 넣고, 제휴 링크에 구글 제휴 표시(rel="sponsored")를 자동으로
AI 기본법 — 2026년 1월부터 생성형 AI 서비스는 이용자에게 미리 알려야 해요.처음 로그인할 때 안내하고, 모든 화면 아래에 표시
AI 모델 — 더 좋은 모델이 계속 나와요.여러분 쪽 설정 없이 서버에서 바로 바꿔 적용

그 밖에 설치 없음(폰·PC 어디서나), AI 키·충전 준비 없음(요금에 포함), 실제 네이버 검색량으로 고르는 키워드도 블로그 도우미만의 장점이에요.

일부러 넣지 않은 기능 — 여러분의 블로그를 지키기 위해서예요

다른 프로그램에 있는 기능넣지 않은 이유
네이버 자동 로그인·자동 발행네이버 운영정책은 자동화 프로그램으로 글을 올리는 것을 막고 있어요. 걸리면 글이 검색에서 빠지거나 블로그가 제한될 수 있어요. 블로그 도우미는 글을 완성해 드리고, 올리는 건 버튼 4번(제목·본문·태그 복사 → 사용 완료)으로 직접 해요.
이웃추가·댓글·좋아요 자동사람인 척하는 자동 활동은 대표적인 어뷰징이라 블로그 지수에 오히려 독이 돼요.
히든 이미지·이미지 세탁·대량 배포검색 순위를 속이거나 남의 사진 저작권을 피하려는 방법이에요. 검색에서 빠지거나 저작권 분쟁이 날 수 있어요.
ChatGPT·Gemini 웹 계정 자동 사용각 서비스 약관이 자동 프로그램 사용을 막고 있어요. 계정이 정지되면 쓰던 유료 구독도 날아가요. 블로그 도우미는 공식 API만 써요.
티스토리 자동 발행티스토리 공식 글쓰기 API가 종료돼서, 지금 되는 프로그램은 비공식 방법을 써요. 언제든 막힐 수 있어요.

빠르게 많이 올리는 것보다 오래 살아남는 블로그가 결국 수익이 나요. 블로그 도우미는 그쪽을 택했어요.

1. 처음 시작하기

  1. 크몽에서 결제할 때 로그인에 쓸 구글 이메일(…@gmail.com)을 판매자에게 알려 주세요.
  2. 판매자가 사용 승인을 하면 안내받은 주소로 들어가 구글로 로그인을 누릅니다.
  3. 처음 한 번 이용약관·개인정보처리방침·환불정책을 확인하고 동의하면 바로 쓸 수 있어요.
  4. "승인 대기 중"이 나오면 화면의 이메일을 복사해 판매자에게 보내 주세요. 다른 구글 계정으로 로그인했을 수도 있어요.

로그인만 하면 PC·폰 어디서든 같은 글과 설정이 그대로 열려요. 화면 오른쪽 위에 요금제와 이번 달 사용량(예: 프로 · 이번 달 12/70편)이 늘 보여요.

메뉴 보는 법 — PC에서는 왼쪽 메뉴에서 할 일을 고르면 오른쪽에 그 내용이 나와요. 메뉴마다 색이 달라서(키워드=초록, 글 만들기=파랑, 발행 관리=주황, 구글 블로그=분홍 …) 지금 어느 화면인지 한눈에 알 수 있고, 메뉴 옆 숫자는 올릴 글 수예요. 폰에서는 화면 아래 메뉴(홈·키워드·글 만들기·구글 블로그)를 누르고, 나머지는 전체 메뉴(☰)에 있어요.

2. 처음 한 번 설정 (3분)

설정 탭 → 글쓰기 설정에서 아래를 넣고 저장을 누릅니다.

칸넣는 법예
블로그 주제키워드는 이 안에서만 찾아요. 1~2개 분야로 좁게 정할수록 검색에서 "전문 블로그"로 보여요.부업, 돈 아끼는 방법
내 네이버 블로그 카테고리쉼표로 4~6개. 글마다 이 중 하나를 추천해 줘요.지원금, 생활비 절약, 할인·혜택, 후기
경험을 쓰기 쉬운 관심 분야 (선택)직접 경험이 있는 분야를 적으면 후보에 섞어 줘요.해외직구
클릭 순서까지 자세한 따라하기신청 방법 같은 글에 "어디 접속 → 무엇 클릭"을 단계별로 넣어요.켜기 추천

3. 키워드 찾기

  1. ① 키워드 찾기 탭에서 키워드 자동찾기를 누르면 1분 안팎으로 후보 20개가 나와요.
    • 네이버 실제 월간 검색량 순으로 정렬되고, 100회 미만은 빠져요.
    • 후보마다 네이버에 적합 / 구글(블로그스팟·워드프레스)에 적합 표시가 붙어요.
    • 이미 글을 쓴 키워드는 다음 후보에서 자동으로 빠져요.
  2. 쓰고 싶은 키워드가 있으면 직접 입력 칸에 넣고 검색량 확인을 눌러 보세요.
  3. 가장 빠른 방법: 홈의 추천 키워드로 글 쓰기 한 번이면 키워드 고르기부터 글 완성까지 알아서 해요.

3-1. 글쓰기 예약 — 키워드 여러 개를 나중에 차례대로

마음에 드는 키워드가 여러 개면, 하나씩 기다릴 필요 없이 담아 두고 한 번에 맡기세요. 메모장이나 엑셀은 필요 없어요.

  1. ① 키워드 찾기에서 후보 카드의 ＋ 예약을 누르면 담겨요(다시 누르면 빠져요). 직접 생각한 키워드는 입력칸에 쓰고 ＋ 예약에 담기.
  2. 화면의 글쓰기 예약 카드에서 ▲▼로 순서를 바꾸고, 키워드마다 네이버 / 연결한 구글 블로그를 고르세요.
  3. 쓰는 방식을 고르세요.
    • 지금부터 차례대로 — 앞 글이 끝나면 다음 글을 바로 써요.
    • 하루 1개 · 2개 · 3개 — 정한 시각(예: 9시)에 서버가 알아서 써요. 2개는 6시간, 3개는 4시간 간격이에요.
  4. N개 예약 시작을 누르면 끝. 창을 닫거나 컴퓨터를 꺼도 서버가 써요. 완성되면 알림이 와요.
네이버는 하루 1~2개를 추천해요. 하루에 한꺼번에 많이 올리면 저품질 위험이 커져요. 예약은 "글을 써 두는 것"까지이고, 네이버에 올리는 건 늘 직접(복사·붙여넣기) 해요.
  • 진행 현황에서 ⏰ 예약 시각 · 대기 · 쓰는 중 · 완성 · 실패를 볼 수 있어요. 아직 시작 전인 글은 취소할 수 있어요(취소한 글은 이번 달 글 수를 쓰지 않아요).
  • 요금제의 이번 달 남은 글 수보다 많이 예약할 수 없어요. 글 수는 실제로 쓴 만큼만 빠져요.
  • 이미 쓴 키워드나 다른 블로그와 겹치는 키워드는 중복 문서를 막기 위해 자동으로 빼고 예약해요.
  • 서버가 바쁘면 예약 시각보다 몇 분 늦게 시작할 수 있어요.

4. 네이버 글 쓰고 올리기

  1. 후보 옆 네이버 글 쓰기를 누르면 서버가 1차 출처와 상위 글을 확인한 뒤 글을 써요. 2~4분 걸리고, 창을 닫아도 계속 써요.
  2. 다 쓴 글은 ② 글 만들기와 왼쪽 목록에 나타나고 자동으로 펼쳐져요.
  3. 글을 열면 큰 버튼 하나가 순서대로 바뀌어요: ① 제목 복사 → ② 본문 복사 → ③ 태그 복사 → ④ 사용 완료. 네이버 글쓰기 화면에 차례로 붙여 넣으세요. (폰에서는 버튼이 화면 아래에 붙어 있어요)
  4. 붙여 넣은 본문의 색 칸을 꼭 채우고 표시를 지우세요.
    • 노란 칸 = 사진 자리. 안내대로 직접 찍은 사진·화면 캡처를 넣어요.
    • 파란 칸 = 경험 자리. 직접 겪은 내용으로 고쳐 쓰세요. 하지 않은 경험을 쓰면 거짓 후기가 돼요.
    • 빨간 칸 = AI가 버튼 이름을 확인하지 못한 곳. 실제 화면을 보고 고쳐 써요.
  5. 글 아래 검증 체크리스트의 ⚠️ 항목은 공고 원문·공식 사이트와 꼭 대조하세요.
  6. 네이버 앱에 붙여 넣은 뒤 임시저장하면 나중에 PC에서 이어서 고칠 수 있어요.
  7. 올렸으면 ④ 사용 완료를 눌러요. 같은 글을 또 복사하려 하면 경고가 떠서 중복 업로드를 막아 줘요.
✍️ 네이버는 "내 글"처럼 올려야 잘 돼요. 네이버는 AI로 글의 신뢰도를 평가하고, 자동 생성 글·경험 없는 글을 걸러내요. 그래서 완성된 글을 그대로 올리기보다:
  • 제목 — 내 말투로 다듬어요(키워드는 남겨 두세요).
  • 본문 — 문장을 내 말로 고치고, 파란 칸은 내가 실제로 겪은 일로 채워요.
  • 사진 — 노란 칸에 직접 찍은 사진이나 화면 캡처를 넣어요. 다른 블로그·뉴스 사진은 쓰지 마세요.
블로그 도우미가 만든 글은 "잘 짜인 뼈대"예요. 여기에 내 손길이 들어가야 검색 노출에 훨씬 유리해요.
네이버는 하루 1~2개만 올리세요. 하루에 여러 개를 한꺼번에 올리면 저품질(검색 누락) 위험이 커져요. 글은 미리 많이 써 둬도 괜찮고, 올리는 것만 하루 1~2개씩 나누면 돼요. 오늘 2개를 올리면 글 화면에 "내일 올리기 추천" 안내가 뜨고, 홈의 "올릴 글" 칸에 오늘 올린 개수가 보여요.
서비스는 네이버에 자동으로 올리지 않아요. 네이버 정책상 자동 업로드·이웃 추가·댓글 자동화는 블로그 제재 위험이 있어 일부러 넣지 않았어요.

5. 발행 관리 (올린 글 정리)

  • ③ 발행 관리에서 만든 글과 사용 완료 여부를 한눈에 봐요.
  • 내 네이버 블로그 아이디(blog.naver.com/아이디)를 한 번 저장해 두면, 지금 찾기로 내가 올린 글의 주소를 자동으로 찾아 채워 줘요(무료). 찾은 글은 블로그스팟·워드프레스 글의 "함께 보면 좋은 글" 링크에도 쓰여요.

6. 블로그스팟 · 워드프레스

계정 연결 (처음 한 번)

  1. ④ 블로그스팟·워드프레스 탭 → + 계정 추가.
  2. 워드프레스를 고르고 사이트 주소(https://…), 사용자 이름, 응용 프로그램 비밀번호를 넣고 저장해요.
    • 응용 프로그램 비밀번호 만드는 법: 워드프레스 관리자 → 사용자 → 프로필 → 맨 아래 응용 프로그램 비밀번호 → 이름에 blog-helper 입력 → 새 응용 프로그램 비밀번호 추가 → 나온 24자리를 복사.
    • 로그인 비밀번호가 아니에요. 언제든 워드프레스에서 지우면 연결이 바로 끊겨요.
    • 입력한 값은 암호화 보관함에 저장되고 화면에는 끝 4자리만 보여요.
  3. 블로그스팟: 구글 계정 연결 버튼은 준비 중이에요. 그 전까지는 판매자에게 연결을 요청해 주세요.
  4. 저장 후 연결 확인 (0원)을 누르면 계정마다 "연결됨"이 표시돼요.

  1. ① 키워드 찾기에서 블로그스팟·워드프레스 글 쓰기 → 어느 계정용인지 고르면 서버가 구글 검색용 글을 써요(5~10분).
  2. 다 쓴 글은 ④ 탭 전송 대기에 나와요. 임시저장으로 또는 바로 공개 발행을 고르고 워드프레스 전송(또는 블로그스팟 전송)을 눌러요.
  3. 품질 검사(분량·키워드·구성·과장 표현·지어낸 경험·예전 글과 겹침·깨진 링크)에 떨어진 글은 공개 발행이 막히고 임시저장으로만 보내요. 블로그마다 하루 공개 2개까지예요.
  4. 같은 글은 두 번 보낼 수 없고, 네이버 글과 같은(비슷한) 키워드로는 쓰지 않아요(중복 문서 방지).

자동 발행 (프로·프리미엄)

계정 카드의 자동 발행 스위치를 켜면 매일 오전 9시쯤·오후 4시쯤 1개씩 알아서 키워드를 골라 쓰고 보내요. 쓴 글은 요금제 글 수에서 빠지며, 한도에 닿으면 쉬어요. 처음에는 임시저장으로 두고 며칠 품질을 확인한 뒤 공개 발행으로 바꾸는 걸 추천해요.

7. 시리즈 글

  1. 네이버 글을 열고 시리즈 편 추천받기를 누르면, 같은 주제로 이어 쓸 후속 편이 추천돼요.
  2. ⑤ 시리즈 글 탭에 모두 모여요. 편마다 네이버 또는 구글 블로그 중 한 곳을 골라 쓰고, (추천) 표시가 붙은 쪽을 고르면 좋아요.
  3. 시리즈 편은 앞 글의 조사 결과를 다시 써서 더 빨리 써져요(글 수는 1편씩 세요). 한 편은 한 곳에만 써서 중복 문서를 막아요.

  • 화면 맨 위에 요금제 · 이번 달 쓴 글 수와 남은 기간이 늘 보여요. 남은 기간이 7일 이하면 노란색, 3일 이하면 빨간색으로 바뀌어요.
  • 글 수는 완성된 글 기준으로 세고, 매달 1일(한국 시간)에 새로 시작해요.
  • 완성된 글을 지워도 그달 사용한 편수는 줄지 않아요.
  • 키워드 찾기·검색량 확인·연결 확인·발행 관리는 글 수에 들어가지 않아요.
  • 한도에 닿으면 새 글 작성이 멈추고 "이번 달 요금제 한도를 다 썼어요"가 표시돼요. 더 필요하면 판매자에게 요금제 변경을 요청하세요.

8-1. 글 형태 · 광고 문구 · 썸네일 · 알림

홈 화면

맨 위 카드 4개에 올릴 글 · 쓰는 중 · 이번 달 남은 편수 · 최근 올린 글이 보여요. 카드를 누르면 해당 화면으로 가요. 처음에는 "처음 시작하기" 4단계가 보이고, 다 하면 사라져요.

글 형태 · 말투 · 추가 요청

  • ① 키워드 찾기 화면의 "이번 글 형태"에서 정보성 / 후기형 / 비교·추천을 고르고 추가 요청 한 줄(예: 표를 꼭 넣고 문단은 짧게)을 적을 수 있어요.
  • 설정 → 내 글쓰기 스타일에서 말투(친근한 해요체 / 담백한 정보형 / 전문가처럼)와 주로 읽는 사람도 정해요.
  • 사실 확인·품질 검사 규칙은 그대로예요. 후기형이어도 경험을 지어내지 않고, 직접 채울 자리를 더 많이 만들어 줘요.

광고 문구 · 제휴 링크 (쿠팡 파트너스·협찬)

  • 네이버 글: 설정 → "네이버 글 광고 문구"에서 문구(쿠팡 파트너스/협찬/광고비)와 링크를 정하고, 글마다 "이 글에 광고 문구 넣기"로 켜고 꺼요. 켜면 본문을 복사할 때 맨 위에 붙어요.
  • 블로그스팟·워드프레스: ④ 탭 계정 수정에서 블로그마다 켜고 꺼요. 보낼 때 글 맨 위에 붙어요.
  • 대가를 받은 글은 반드시 표시해야 해요(공정위 지침). 받지 않은 글에는 끄세요.

대표 썸네일

글을 열면 대표 썸네일이 자동으로 그려져요(비용 0원). 색 6가지, 정사각(네이버)·가로(구글 1200×630), 큰 글자를 바꾸고 "썸네일 저장"으로 내려받아 글 맨 위에 넣으세요. ④ 탭 "내용 보기"에도 있어요.

진행 단계 · 완성 알림

쓰는 중인 글은 자료 조사 → 글쓰기 → 품질 검사 → 완성 중 어디쯤인지 보여요. 설정 → 화면 설정의 🔔 완성 알림 켜기를 누르면, 다른 창을 보고 있어도 글이 완성될 때 알림이 와요(이 기기 · 창이 열려 있을 때).

9. 좋은 글로 키우는 습관 · 주의

  • 올리기 전 5분 확인: 숫자·날짜·신청 기간은 공식 사이트와 대조하고, 파란 칸 경험은 내 이야기로 바꿔요. AI가 쓴 초안은 틀릴 수 있어요.
  • 사진은 직접: 다른 블로그·뉴스 사진은 저작권 침해예요. AI 그림을 실제 사진처럼 쓰는 것도 피하세요.
  • 같은 글을 여러 블로그에 그대로 올리지 마세요. 검색에서 한 곳만 남고 나머지는 숨겨져요.
  • 꾸준함: 네이버 하루 1~2개, 구글 블로그 하루 1~2개를 몇 주 꾸준히 올리는 게 한 번에 많이 올리는 것보다 좋아요.
  • 광고·협찬 글은 "광고" 표시를 해야 해요(공정위 지침).

10. 자주 묻는 질문

글쓰기 버튼을 눌렀는데 글이 안 나와요.

네이버 글은 2~4분, 구글 블로그 글은 5~10분 걸려요. 다른 글을 쓰는 중이면 그다음에 처리돼요. 창을 닫아도 서버가 계속 쓰니 나중에 다시 열어 보세요. 15분이 지나도 안 나오면 판매자에게 알려 주세요.

폰과 PC에서 같이 쓸 수 있나요?

네. 같은 구글 계정으로 로그인하면 글·설정·사용 완료 표시가 모두 같이 보여요.

워드프레스 연결 확인이 실패해요.

"로그인 실패"면 사용자 이름이나 응용 프로그램 비밀번호가 틀린 거예요. 새로 만들어 계정 수정에서 다시 넣으세요. "권한 부족"이면 글 발행 권한이 있는 계정(관리자·편집자)인지 확인하세요. 보안 플러그인이 REST API를 막고 있을 수도 있어요.

화면이 너무 밝아요 / 어두워요.

맨 위 로고 옆 ☀/☾ 버튼으로 화이트·블랙을 바꾸고, 설정 → 화면 설정에서 밝기(60~120%)를 조절해요. 폰과 PC에 따로 적용돼요.

공용 PC에서 썼어요.

설정 → 로그아웃 + 이 기기에서 키 지우기로 로그아웃하세요. 내 계정의 글과 설정은 그대로 남아요.

그만 쓰고 싶어요 / 내 데이터는요?

홈의 전체 백업 받기로 글을 내려받은 뒤 판매자에게 해지를 요청하세요. 환불은 환불정책을 따르고, 데이터는 30일 안에 지워져요.
