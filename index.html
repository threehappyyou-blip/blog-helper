블로그 도우미

키워드 찾기 · 네이버 6개 + 워드프레스 1개 초안 · 발행 관리

처음이세요? 도움말을 열고 위에서부터 따라 하세요. 설정 → 키워드 찾기 → 글 만들기 → 직접 업로드 순서입니다.

전체 백업

키워드·글·발행 기록·설정을 파일 하나로 저장하고 다른 기기에서 그대로 되살립니다(API 키는 빼고).

① 키워드 찾기

지금 뜨는 키워드를 찾거나, 직접 입력해서 바로 글을 만들 수 있습니다.

최근 뉴스·정부/지자체 공고를 검색해 후보 6개를 찾습니다. 1~2분 걸립니다.

② 글 만들기

③ 발행 관리

블로그에 올린 글은 사용 완료로 체크해 두세요. 네이버는 하루 1~2개씩 나눠 올리는 게 안전합니다.

설정

Claude API 키

이 기기의 브라우저에만 저장되고, Claude 서버로만 전송됩니다. 백업 파일에도 들어가지 않습니다.

글쓰는 곳

이 기기의 브라우저에만 저장됩니다. 폰과 PC에 각각 한 번씩 넣으면 같은 글 목록과 사용 완료 표시가 공유됩니다.

글쓰기 설정

4~6개 권장. 글마다 이 중 하나를 추천해 줍니다.
키워드 후보에 이 분야를 1개 이상 섞어 줍니다.
"어디 접속 → 무엇 클릭 → 무엇 입력 → 아래로 내려 → 무엇 클릭"을 단계별 사진 자리와 함께 씁니다. 글이 길어지고 비용이 조금 늘어납니다.
기본값 claude-sonnet-5-5. 바꿀 일이 없으면 그대로 두세요.

데이터 지우기

키워드·글·발행 기록을 모두 지웁니다. 먼저 홈에서 백업을 받아두세요.

도움말

1. 준비 (처음 한 번)

  1. Claude Console(platform.claude.com)에서 API 키를 만들고 크레딧을 충전합니다. 월 사용 한도도 꼭 걸어두세요.
  2. 설정 탭에 API 키를 넣고 연결 확인을 누릅니다.
  3. 설정 탭에 내 네이버 카테고리를 적습니다.

2. 글 만들기

  1. ① 키워드 찾기에서 키워드 자동찾기를 누르고 후보 중 하나를 고릅니다.
  2. 자동으로 1차 출처를 모으고, 상위글을 분석한 뒤 글 7개(네이버 6 + 워드프레스 1)를 씁니다. 글을 1개씩 차례로 쓰고, 다 쓴 글은 왼쪽 목록에 바로 나타납니다. 다른 탭을 봐도 계속 쓰며, 탭이 닫혔다가 다시 열리면 이어서 씁니다.
  3. 7개 글은 모두 메인 키워드를 제목과 본문에 넣되, 서로 다른 세부 주제를 맡습니다. 같은 내용 반복은 유사문서로 묶이기 때문입니다.

3. 업로드 (직접)

  1. 글 카드를 열어 제목을 손보고 제목 복사 → 네이버 글쓰기에 붙여넣기.
  2. 본문 복사(서식) → 붙여넣기. 노란 칸은 사진, 파란 칸은 경험 자리입니다. 채운 뒤 표시를 지우세요.
  3. 사진 가이드대로 화면을 캡처해서 넣고, 경험 예시는 직접 확인한 내용으로 고쳐 씁니다.
  4. 검증 체크리스트에서 ⚠️ 항목은 공고 원문과 꼭 대조하세요.
  5. 따라하기의 빨간 칸은 AI가 출처에서 버튼 이름을 확인하지 못한 곳입니다. 단계별 사진을 찍으면서 실제 버튼 이름으로 고쳐 쓰세요.
  6. 올렸으면 사용 완료로 표시 버튼을 누릅니다. 왼쪽 목록에 ✓가 붙고, 다시 복사하려 하면 경고가 떠서 중복 업로드를 막아줍니다.

주의

  • 같은 글을 여러 블로그에 그대로 올리지 마세요. 검색에서 한 곳만 남고 나머지는 숨겨집니다.
  • 다른 블로그·뉴스 사진은 쓰지 마세요(저작권). AI 이미지를 실제 사진처럼 쓰는 것도 피하세요.
  • 확인하지 않은 경험 예시를 그대로 쓰면 거짓 경험이 됩니다.
