블로그 도우미
1키워드 · 글 쓰기
실제로 검색되는 키워드를 골라 리서치부터 글 완성까지 한 번에 진행해요. 이미 쓴 키워드는 빠져요.
처음이세요? 도움말을 열고 위에서부터 따라 하세요.

전체 백업

키워드·글·발행 기록·설정을 파일 하나로 저장하고 다른 기기에서 그대로 되살립니다(API 키는 빼고).

① 키워드 찾기

키워드 1개로 글 1개를 씁니다. 후보를 찾거나 직접 입력하세요.

블로그 주제 안에서 서로 다른 후보 20개(장기형 위주)를 찾고, 월 검색량 100회 미만은 뺍니다. 이미 글을 쓴 키워드는 빠집니다. 1분 안팎. (주제는 설정에서 바꿔요)

② 글 만들기

③ 발행 관리

블로그에 올린 글은 사용 완료로 체크해 두세요. 네이버는 하루 1~2개씩 나눠 올리는 게 안전합니다.

④ 블로그스팟 · 워드프레스

키워드로 글을 쓰고 → 보낼 계정을 확인하고 → 전송 버튼으로 올려요. 품질 검사를 통과하지 못한 글은 공개 발행이 막혀요. 자동 발행은 계정마다 따로 켜요.

⑤ 시리즈 글

네이버 글에서 나온 시리즈 글감을 한곳에 모았어요. 편마다 네이버 또는 구글 블로그(블로그스팟·워드프레스) 중 한 곳을 골라 써요. 한 편은 한 곳에만 써서 중복 문서를 막아요.

설정

Claude API 키

이 기기의 브라우저에만 저장되고, Claude 서버로만 전송됩니다. 백업 파일에도 들어가지 않습니다.

GitHub 연결 · 글쓰는 곳

GitHub를 연결하면 실제 검색량 조회와 서버 글쓰기를 쓸 수 있어요.
이 기기의 브라우저에만 저장됩니다. 폰과 PC에 각각 한 번씩 넣으면 같은 글 목록과 사용 완료 표시가 공유됩니다.

글쓰기 설정

네이버는 한 분야에 집중한 블로그를 더 자주 인용해요. 1~2개 분야로 좁게 정하세요.
4~6개 권장. 글마다 이 중 하나를 추천해 줍니다.
키워드 후보에 이 분야를 1개 이상 섞어 줍니다.
"어디 접속 → 무엇 클릭 → 무엇 입력 → 아래로 내려 → 무엇 클릭"을 단계별 사진 자리와 함께 씁니다. 글이 길어지고 비용이 조금 늘어납니다.

비용 · 모델

이번 달 사용 금액이 예산에 닿으면 사이트와 서버 모두 자동으로 멈춥니다. 매달 1일에 초기화됩니다.

AI 그림 (선택)

warminsight에서 쓰는 구글 키를 그대로 써도 돼요. 이 기기 브라우저에만 저장돼요. 버튼을 누를 때만 만들어서 모르는 사이 돈이 나가지 않아요.

워드프레스 연결 (임시글 보내기)

워드프레스 관리자 → 사용자 → 프로필 맨 아래 "애플리케이션 비밀번호"에서 만듭니다. 이 기기 브라우저에만 저장됩니다.

데이터 지우기

키워드·글·발행 기록을 모두 지웁니다. 먼저 홈에서 백업을 받아두세요.

도움말

1. 준비 (처음 한 번)

  1. Claude Console(platform.claude.com)에서 API 키를 만들고 크레딧을 충전합니다. 월 사용 한도도 꼭 걸어두세요.
  2. 설정 탭에 API 키를 넣고 연결 확인을 누릅니다.
  3. 설정 탭에 내 네이버 카테고리를 적습니다.

2. 글 만들기

  1. ① 키워드 찾기에서 키워드 자동찾기를 누르고, 후보마다 네이버 글 쓰기 또는 워드프레스 글 쓰기를 누릅니다. 키워드 1개로 글 1개를 씁니다.
  2. 그 키워드의 1차 출처와 상위글을 확인한 뒤 글 1개를 씁니다. 2~4분 걸리고, 다 쓴 글은 왼쪽 목록에 나타납니다.
  3. 여러 글이 필요하면 키워드를 하나씩 더 고르세요. 이미 쓴 키워드는 다음 후보에서 자동으로 빠집니다.

3. 업로드 (직접)

  1. 글 카드를 열어 제목을 손보고 제목 복사 → 네이버 글쓰기에 붙여넣기.
  2. 본문 복사(서식) → 붙여넣기. 노란 칸은 사진, 파란 칸은 경험 자리입니다. 채운 뒤 표시를 지우세요.
  3. 사진 가이드대로 화면을 캡처해서 넣고, 경험 예시는 직접 확인한 내용으로 고쳐 씁니다.
  4. 검증 체크리스트에서 ⚠️ 항목은 공고 원문과 꼭 대조하세요.
  5. 따라하기의 빨간 칸은 AI가 출처에서 버튼 이름을 확인하지 못한 곳입니다. 단계별 사진을 찍으면서 실제 버튼 이름으로 고쳐 쓰세요.
  6. 올렸으면 사용 완료로 표시 버튼을 누릅니다. 왼쪽 목록에 ✓가 붙고, 다시 복사하려 하면 경고가 떠서 중복 업로드를 막아줍니다.

버튼 하나로 쓰기 · 비용

  • 홈의 추천 키워드로 글 쓰기 한 번이면 키워드 찾기 → 가장 좋은 키워드 → 글 완성까지 진행합니다. 누르기 전에 예상 비용을 알려줍니다.
  • 글을 열면 ① 제목 복사 → ② 본문 복사 → ③ 태그 복사 → ④ 사용 완료 버튼 하나가 순서대로 바뀝니다. 폰에서는 화면 아래에 붙어 있습니다.
  • 네이버는 앱에 붙여넣은 뒤 임시저장을 누르면 나중에 앱·PC에서 이어서 고칠 수 있습니다. (네이버는 자동 임시저장 공식 기능이 없습니다)
  • 워드프레스는 설정에서 연결하면 임시글로 보내기 버튼 하나로 임시글이 만들어지고, 고친 뒤 다시 누르면 같은 임시글이 업데이트됩니다.
  • 위쪽에 이번 달 사용 금액 / 예산이 늘 보입니다. 예산에 닿으면 사이트와 서버 모두 자동으로 멈춥니다. 설정 → 비용·모델에서 바꿉니다.
  • 글마다 SEO 점수와 빠진 항목이 나옵니다. 사이트가 직접 계산해서 비용이 들지 않습니다.

④ 블로그스팟 · 워드프레스

  • 처음 한 번: 설정 가이드대로 GitHub Secrets에 구글(블로그스팟)·워드프레스 로그인 정보를 넣고, ④ 탭에서 + 계정 추가 → 연결 확인.
  • ① 키워드 찾기에서 블로그스팟·워드프레스 글 쓰기를 누르면 어느 계정용인지 고르는 창이 떠요. 서버가 상위 글 1~3개를 비교해 구글용 글을 써요(5~10분).
  • 다 쓴 글은 ④ 탭 전송 대기에 나와요. 보낼 계정 이름을 확인하고 블로그스팟 전송 / 워드프레스 전송을 누르면 돼요. 공개 발행 또는 임시저장을 고를 수 있어요.
  • 품질 검사(분량·키워드·구성·과장 표현·지어낸 경험·예전 글과 겹침·깨진 링크)에 떨어진 글은 공개 발행이 막히고 임시저장으로만 보내요. 블로그마다 하루 공개 2개까지예요.
  • 같은 글을 두 번 보내지 못하게 막아요. 네이버 글·다른 블로그 글과 같은(비슷한) 키워드로는 쓰지 않아요.
  • 자동 발행은 계정마다 스위치로 따로 켜요. 켜면 매일 오전·오후에 1개씩 알아서 쓰고 보내요.

주의

  • 같은 글을 여러 블로그에 그대로 올리지 마세요. 검색에서 한 곳만 남고 나머지는 숨겨집니다.
  • 다른 블로그·뉴스 사진은 쓰지 마세요(저작권). AI 이미지를 실제 사진처럼 쓰는 것도 피하세요.
  • 확인하지 않은 경험 예시를 그대로 쓰면 거짓 경험이 됩니다.
